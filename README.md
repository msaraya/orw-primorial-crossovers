## Abstract

Let \(P=p_k^\#\) and \(q=p_{k+1}\), so that \(qP=p_{k+1}^\#\) is the next primorial. We study the pairwise crossover between these two candidates in the explicit Odlyzko–Rubinstein–Wolf (ORW) exponential-integral approximation

\[
\mathcal M(X,D)=\mathfrak S(D)I_D(X), \qquad
I_D(X)=\int_2^X \frac{\exp(-D/\log t)}{(\log t)^2}\,dt.
\]

Writing \(L=\log X\), we prove a uniform all-orders endpoint expansion for \(I_D(e^L)\) whose coefficients are \(j!L_j^{(1)}(D/L)\), with remainder control stable under differentiation in the growing endpoint parameter. We then reorganize the logarithmic expansion into a graded asymptotic scale and rigorously invert the full crossover equation. If

\[
L_0=\frac{(q-1)P}{\log((q-1)/(q-2))}
\]

is the exact solution of ORW's leading exponential comparison, then for every fixed \(M\)

\[
L_{\rm int}=L_0+\sum_{m=0}^{M}\frac{c_m(P,qP)}{L_0^m}
+O_M\!\left(\frac{(1+qP)^{\lfloor(M+1)/2\rfloor}}{L_0^{M+1}}\right),
\]

where \(\deg c_m\le\lfloor m/2\rfloor\) and the coefficients are generated by an explicit Lagrange–Bürmann formula. In particular,

\[
L_{\rm int}=L_0+1+\frac{3}{L_0}
+O\!\left(\frac{1+qP}{L_0^2}\right).
\]

The corrections \(1\) and \(3/L_0\) are universal for general endpoint pairs with \(D_1/L_0\to0\). The results are theorems about the stated ORW approximation; no unconditional claim about actual jumping champions is made.

**Keywords:** jumping champions; prime gaps; primorials; generalized Laguerre polynomials; asymptotic inversion.

## Scope

The results concern the explicitly defined Odlyzko–Rubinstein–Wolf exponential-integral approximation. The paper makes no unconditional claim about actual jumping champions.

## Reproducing the numerical check

The script requires Python 3 and [`mpmath`](https://mpmath.org/):

```bash
python -m pip install mpmath
python code/numerical_check.py
```

The numerical computation is ancillary; none of the proofs depends on it.
